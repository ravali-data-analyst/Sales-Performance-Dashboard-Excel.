# Sales-Performance-Dashboard-Excel.
Interactive Excel Sales Dashboard using Pivot Tables, Charts and Business KPIs

# Project Overview
This project analyzes sales and profit performance using Microsoft Excel. The dashboard was built using Pivot Tables, Pivot Charts, Slicers, and KPI metrics to provide business insights and support decision-making.

# Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Visualization

# Key Business Metrics
Total Sales
Total Profit
Sales by Category
Sales by Region
Monthly Sales Trends
Product Performance Analysis
